# NYC 311 Complaints Analysis

Analysis of NYC 311 service requests in Brooklyn using SQL (SQLite) and Python.

## Questions
1. Which complaint types are most common in Brooklyn?
2. Which zip codes generate the most complaints, and of what type?
3. When do complaints peak (hour, weekday, month)?
4. How quickly do different agencies resolve complaints?
5. Do response times differ meaningfully between neighborhoods?
